# Olympiad Quest — Age 7

## Publish
Upload all files in this folder to a GitHub repository. GitHub Pages publishes static HTML/CSS/JavaScript files directly from a repository.

Make sure `index.html` is at the top level of the publishing source.

## iPad
Open the published URL in Safari, then use Share → Add to Home Screen. The manifest requests standalone display, so it behaves like a home-screen web app.

## Included
- Math, Science, English, GK and Reasoning
- Mixed quiz
- Randomized questions
- Instant explanations
- Stars, levels and streak
- Offline service worker
